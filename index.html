Challenge

從封閉式設備，跨出數位化的第一步

傳統混煉設備多以實體按鈕與旋鈕操作，缺乏資料保存與外部通訊能力。當客戶開始要求數據透明、產線互通與遠端管理，既有設備就面臨明顯限制。

01

設備資訊不透明

加工數值分散於現場，難以即時視覺化與集中掌握。

02

配方與紀錄難管理

配方輸入、警報與生產紀錄依賴人工處理，容易增加操作負擔。

03

缺乏外部資料介接

封閉式架構不易與 MES、ERP、雲端或其他管理系統整合。

Core Platform

一套架構，串起機台、資料與應用

以 IPC 作為智慧化載具，向下整合 PLC 與現場設備，向上提供資料庫、API 與遠端應用，逐步建立可擴充的設備智慧化基礎。

Open Integration

讓設備資料真正能被系統使用

自有介面進一步提供 API 介接能力，外部系統可依權限取得機台狀態、警報、配方、加工與歷史資料，形成智慧工廠所需的資料流。

HTTP / HTTPS · Auth · JSON
連線與身分驗證支援 HTTP / HTTPS 介接。
設備狀態查詢取得感測器、馬達與燈號等即時狀態。
警報狀態查詢取得目前警報與異常狀態。
配方資訊與操作查詢、新增、修改與刪除配方資料。
加工資訊查詢取得目前配方與加工開始、結束、總時間。
歷史資料查詢取得歷史警報與歷史點位數值。
Remote Solutions

透過既有 API 架構，將單機資料延伸至遠端配方管理、工廠產線儀表板與行動監控 App，建立跨設備的管理視角。

遠端配方管理
